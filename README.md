# english — Английский язык для кораблестроителей

Статический учебный сайт (чистые HTML/CSS/JS, без сборки) — «суперучебник»
английского языка для судостроительных специальностей: любое английское слово
произносится по щелчку, любой текст читается вслух по предложениям, к каждой
теме есть тренажёр с автопроверкой.

**Прод:** https://shadeswd.duckdns.org/english/

## О сайте

Порядок материала повторяет пособие кафедры иностранных языков СПбГМТУ
«Sailing out» (7 юнитов: грамматика — разговорная тема — речевой этикет —
тематический словарь). К нему добавлены технические тексты о постройке судна,
сварке и чертежах, пять иллюстраций с английскими подписями, словарь курса и
шесть тренажёров.

Тексты и упражнения написаны заново на материале источников; страницы учебников
не воспроизводятся. Список источников — на странице `sources.html`.

## Состав

27 страниц: обзор, программа курса, семь юнитов, три технических текста,
пять иллюстраций, шесть тренажёров и их сводка, словарь курса, источники.
Словарь — 275 слов и устойчивых сочетаний с транскрипцией, переводом,
примером и ссылками на страницы, где слово встречается.

## Содержание

- `site/` — сам сайт
  - `index.html` — обзор курса, карта, демонстрация произношения
  - `units.html` — программа курса; `u1`…`u7` — юниты
  - `reading.html` — указатель текстов; `r-yard`, `r-welding`, `r-drawing`
  - `pictures.html` — указатель иллюстраций; `pic-ship`, `pic-yard`,
    `pic-engine`, `pic-bridge`, `pic-tools`
  - `drills.html` — тренажёры и сводный прогресс; `d-cards`, `d-gaps`,
    `d-match`, `d-dictation`, `d-order`, `d-grammar`
  - `vocab.html` — словарь курса с поиском и фильтром по темам
  - `sources.html` — источники
  - `assets/`
    - `site.js` — каркас страниц (шапка, навигация, подвал)
    - `style.css` — тема курса
    - `vocab.js` — словарь курса (данные)
    - `speak.js` — разметка английского текста, произношение слова по клику,
      чтение блока вслух
    - `drill.js` — общий движок тренажёров, автопроверка, прогресс,
      интервальное повторение
    - `pics.js` — мини-иллюстрации для тренажёра «слово и картинка»
    - `lists.js` — списки слов и страница словаря
- `tests/test_site.py` — тесты целостности (переносимый набор кластера)
- `deploy/` — docker compose (nginx:alpine, порт 8093)

## Как устроено произношение

`speak.js` во время загрузки обходит элементы с классом `en`, режет текст на
предложения (`span.s`) и слова (`span.w`). Щелчок по слову вызывает
`speechSynthesis.speak` с английским голосом (предпочтение en-GB, затем en-US)
и показывает карточку из словаря. Кнопка «прочитать» над блоком читает его по
предложениям с подсветкой текущего; есть скорость, пауза и остановка.

Если английского голоса в системе нет, страница выводит объяснение и продолжает
работать без звука.

## Запуск

```sh
cd deploy && docker compose up -d      # http://127.0.0.1:8093/
python3 -m pytest tests -q             # тесты целостности
```
