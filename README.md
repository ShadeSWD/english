# english — Английский язык для кораблестроителей

Статический учебный сайт (чистые HTML/CSS/JS, без сборки) — «суперучебник»
английского языка для судостроительных специальностей: любое английское слово
произносится по щелчку, любой текст читается вслух по предложениям, к каждой
теме есть тренажёр с автопроверкой.

**Прод:** https://shadeswd.duckdns.org/english/

## О сайте

Порядок материала повторяет пособие кафедры иностранных языков СПбГМТУ
«Sailing out» (7 юнитов: грамматика — разговорная тема — речевой этикет —
тематический словарь). К нему добавлены технические тексты о постройке судна,
сварке и чертежах, пять иллюстраций с английскими подписями, словарь курса и
шесть тренажёров.

Перед юнитами стоит ступень **«С нуля» (A0–A1)** — для тех, кто языка не знает
вовсе: алфавит и звуки букв, правила чтения, транскрипция, базовая грамматика
пятью страницами (от местоимений и `to be` до `Past Simple`) и первая тысяча
слов двадцатью тематическими блоками по пятьдесят.

Поверх пособия стоит **верхняя ступень «Технический английский» (B1–B2)** —
раздел, который доводит студента до рабочего языка специальности: десять
технических текстов по предметам кластера (конструкция корпуса, сварка,
судовые энергетические установки, коррозия и защита, проектирование, испытания
и приёмка, судовые системы, техника безопасности, чертёж и допуски, качество и
контроль), пять разборов языка документации (страдательный залог и безличные
конструкции; `shall`, `must`, `is to be`; условные предложения; причастные
обороты; числа, размеры, допуски и единицы вслух) и четыре страницы о
собственной речи — деловое письмо, аннотация статьи, доклад на конференции и
чтение научной статьи. Терминология согласована со словарём кластера
(`refbook`) и с сайтами `hullstruct`, `welding`, `shipeng`, `corrosion`,
`shiptech`, `metrology`, `shipsys`.

Тексты и упражнения написаны заново на материале источников; страницы учебников
не воспроизводятся. Список источников — на странице `sources.html`.

## Состав

67 страниц: обзор, ступень «с нуля», программа курса, семь юнитов, тексты
пособия, три простых технических текста, раздел «Технический английский»
(указатель, десять текстов, пять разборов языка документации, четыре страницы
о письме, докладе и статье), пять иллюстраций, шесть тренажёров и их сводка,
словарь курса, источники.

Верхняя ступень: 10 технических текстов общим объёмом 4 479 английских слов,
88 заданий в четырёх банках (`tasks-txt.js`, `tasks-txt2.js`, `tasks-doc.js`,
`tasks-biz.js`), 580 словарных статей.

Словарь курса — больше полутора тысяч слов и устойчивых сочетаний с
транскрипцией, переводом, примером и ссылками на страницы, где слово
встречается.

## Как устроено произношение

`speak.js` во время загрузки обходит элементы с классом `en`, режет текст на
предложения (`span.s`) и слова (`span.w`). Щелчок по слову вызывает
`speechSynthesis.speak` с английским голосом (предпочтение en-GB, затем en-US)
и показывает карточку из словаря. Кнопка «прочитать» над блоком читает его по
предложениям с подсветкой текущего; есть скорость, пауза и остановка.

Если английского голоса в системе нет, страница выводит объяснение и продолжает
работать без звука.

## Запуск

```sh
cd deploy && docker compose up -d      # http://127.0.0.1:8093/
python3 -m pytest tests -q             # тесты целостности
```
